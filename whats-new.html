Improvements & Bug Fixes (v2.1.0)
  • ✦
    Structured AI Output
    AI analysis now uses schema-constrained decoding: the local model can only produce valid JSON with the expected fields. Eliminates "AI returned invalid JSON" failures and makes small models (0.5B and under) reliable for job extraction.
  • 🛡️
    Fixed: Storage Race Conditions
    Concurrent saves from multiple tabs or devices could silently overwrite each other's Notion page IDs. All storage writes are now serialized through a mutex.
  • 🔗
    Fixed: Notion Sync Error Blocking AI
    A Notion API error during bulk processing caused AI analysis to be skipped entirely. AI now runs regardless of Notion sync status.
  • 🔒
    Fixed: URL Save Lock Order
    The URL write lock was released before checking for storage errors, allowing a brief race window on failed saves.
  • 🧭
    Fixed: SPA Navigation Resilience
    LinkedIn's pushState/replaceState overrides now use try/finally so navigation detection continues even if the original call throws.
  • 📊
    Dashboard: Activity Feed Survives Refresh
    Server now replays the last 200 events to new WebSocket connections — the live activity feed is no longer lost on page refresh.
  • 🧹
    Dashboard: Notion Cleanup Tool
    New panel in the server dashboard to find and remove duplicate Notion entries by URL. Dry-run preview before committing.
